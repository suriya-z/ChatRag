      How to Generate a Webhook Secret
      

        

          

            
What is a Webhook Secret?

            
A webhook secret is used to verify that incoming webhook requests are legitimate. Your Baileys instance will sign each request with this secret using HMAC-SHA256, and ChatRAG will verify the signature to ensure security.

          

        


        

          

            
Generation Methods:


            

              
Command Line (Recommended):

              openssl rand -hex 32
            


            

              
Node.js:

              require('crypto').randomBytes(32).toString('hex')
            


            

              
Python:

              import secrets; print(secrets.token_hex(32))
            

          


          

            

              
Security Note: Avoid using online generators for production secrets as they may log or store your generated values.

            

          


          

            
Generate one locally with:

            openssl rand -hex 32
          


          

            

              
Note: While optional, using a webhook secret is highly recommended for production environments to prevent unauthorized webhook calls.

Title Generation Model

    
Choose the AI model used to generate descriptive titles for saved chats.


    

      

        
        CHAT_TITLE_MODEL
      

      
Claude Haiku 4.5 provides excellent instruction following for natural, contextual titles with fast generation (~1 second).

      
    


    

      

        
        CHAT_TITLE_TEMPERATURE
      

      
Moderate values (0.4-0.6) balance creativity with consistency. Use 0.5 for natural rephrasing.

      
    


    

      

        
        CHAT_TITLE_MAX_TOKENS
      

      
Maximum tokens for title generation. 100 tokens is sufficient for concise 3-7 word titles.

      
    

  


  
  

    
Title Generation Information

    

      

        
How it works

        
    
          
  • AI analyzes the conversation context
    • 
          
  • Generates descriptive, context-aware titles
    • 
          
  • Pure AI approach - no algorithms or rules
    • 
          
  • Transforms questions into natural statements
    • 
          
  • Updates asynchronously (~1 second)
    • 
        

      

      

        
Best practices

        
    
          
  • Claude Haiku 4.5 recommended for speed
    • 
          
  • Temperature 0.5 for natural rephrasing
    • 
          
  • 100 tokens sufficient for concise titles
    • 
          
  • Fast models minimize latency
    • 
          
  • Consider costs for high-volume usage
